# Hyprland config

Hyprland 0.57 on the Hyprland laptop (`wray@10.0.0.5`), based on the KooL dots.
This directory mirrors that machine's `~/.config/hypr` file for file (this
README is the only extra). niri does not read it; the niri setup is
self-contained in `../niri/`.

## Which file is live

`hyprland.lua` is the live config: Hyprland 0.57 loads it and ignores
`hyprland.conf`. The KooL `.conf` tree (`hyprland.conf`, `configs/`,
`UserConfigs/`, `lua/`, `animations/`, `v2.3.*` snapshots) is still present
because the KooL menu scripts (`UserConfigsSwitcher.sh`, `Kool_Quick_Settings.sh`,
`Animations.sh`, `KeyBinds.sh`) edit those files, but editing them does not
change the running session. Monitors, autostart, environment, settings,
animations, keybinds, window rules and layer rules are all in `hyprland.lua`, in
that order. The only `require` is `hyprmon.lua` at the end (monitor layout
written by HyprMon, which overrides the monitor block above it).

| Path | Role |
|---|---|
| `hyprland.lua` | The live config (see above). |
| `hyprmon.lua` | Monitor layout generated by HyprMon. |
| `monitors.conf`, `workspaces.conf`, `Monitor_Profiles/` | Read by `scripts/MonitorProfiles.sh` and `scripts/PersistWorkspaceLayout.sh`. |
| `scripts/` | KooL helper scripts the binds, waybar and swaync call (Volume, Brightness, ScreenShot, LockScreen, Wlogout, Dropterminal, ...). |
| `UserScripts/` | Own scripts: wallpaper select/random/effects, RofiBeats, RofiCalc, ZshChangeTheme, Weather. |
| `hypridle.conf` | Idle policy: notify at 9 min, lock at 10 min. |
| `hyprlock*.conf` | Lock screen (`hyprlock.conf`, plus 1080p and 2k variants). |
| `wallust/`, `wallpaper_effects/` | Palette template and wallpaper effect output, read by wallust and rofi. |

To change a bind, edit `hyprland.lua` (section `KEYBINDINGS`) and run
`hyprctl reload`; `hyprctl configerrors` lists parse errors.

## `hyprland.lua` sections

1. **Monitors**: the Lenovo internal panel (2880x1800, scale 1.5), the Hisense
   external display on its right, and a fallback for any other output.
2. **Autostart** (`hyprland.start`): polkit agent, nm-applet, swaync, waybar,
   hypridle, Hyprsunset (night light), two cliphist watchers, wallpaper daemon,
   blueman-applet, fcitx5, and the dropdown terminal (`Dropterminal.sh`).
3. **Environment**: session identity, Qt/GTK/Electron Wayland variables, cursor
   and input-method variables.
4. **Settings**: dwindle and master layouts, 2 px borders, gaps 2/4, rounding
   10, blur (size 6, 3 passes), shadow, touchpad (natural scroll, tap to click),
   workspace swipe gestures, VRR, misc.
5. **Animations**: Bezier curves and per-leaf animation speeds.
6. **Keybindings**: below.
7. **Window rules**: opacity per tag, floating dialogs, picture-in-picture,
   pavucontrol, idle inhibit on fullscreen.
8. **Layer rules**: blur for rofi, swaync (control centre and popups), waybar.

## Key bindings

Main modifier `SUPER` (`Mod`). `Mod+H` opens the KooL cheat sheet and
`Mod+Shift+K` searches the bind list.

| Keys | Action |
|---|---|

| `Ctrl+Alt+B` | Default browser |
| `Mod+X` | Terminal (kitty) |

| Keys | Action |
|---|---|

| `Mod+Ctrl+1` .. `Mod+Ctrl+0` | Move window to workspace 1..10 |
| `Mod+Ctrl+[` / `Mod+Ctrl+]` | Move window to previous / next workspace |

next/previous, then workspace next/previous, `m+1`/`m-1`). Not checked which
one takes effect; `hyprctl binds` in a running session shows it.
